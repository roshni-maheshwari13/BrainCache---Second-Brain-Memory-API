# BrainCache – Second Brain Memory System  
### 👩‍💻 Developed by Roshni Maheshwari  

## Project Overview  
In today’s digital era, individuals manage a large amount of personal information such as notes, ideas, and tasks. However, retrieving this information efficiently is a major challenge.  

Traditional systems rely on keyword-based search, which fails when exact words are not remembered.  

**BrainCache** solves this problem using **AI and NLP-based semantic search**, allowing users to retrieve information based on meaning rather than exact keywords.  

## Key Objectives  
- Develop intelligent memory storage system  
- Implement semantic search using AI  
- Provide fast and accurate retrieval  
- Enable tagging and pinning features  
- Design user-friendly interface  

## Modules  
- Memory Storage  
- Semantic Search  
- Tagging System  
- Pin Feature  
- User Session  

## Tech Stack  
**Backend:** Python, FastAPI  
**Database:** MongoDB  
**Frontend:** HTML, CSS, JS  
**AI Model:** Sentence Transformers  

## Features  
- Semantic search  
- Tagging & filtering  
- Pin important memories  
- Memory summary  
- Fast performance  

## Future Scope
